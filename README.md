# 🚢 Titanic AI Survival Predictor

An artificial intelligence project that predicts passenger survival on the Titanic using machine learning concepts.

## 📖 About

This project analyzes the Titanic disaster and predicts whether a passenger would survive based on their characteristics like class, gender, age, and more. It demonstrates core AI/ML concepts without requiring any external dependencies.

## 🎯 Features

- **Data Generation**: Creates realistic Titanic passenger data
- **Data Analysis**: Shows survival statistics by class, gender, age
- **AI Model**: Machine learning model to predict survival
- **Interactive Predictions**: Predict survival for custom passengers
- **No Dependencies**: Uses only built-in Python libraries
